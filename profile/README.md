# Aurora Lab

Agent skills for researchers: publication-ready figures, manuscripts checked against their data, talks,
posters and research code. Every skill is a plain `SKILL.md`, so it works in Claude Code, Codex, Cursor,
Gemini CLI and any other agent that loads skills.

- **Docs and examples:** [the-aurora-lab.github.io](https://the-aurora-lab.github.io)
- **Free skills:** [the-aurora-lab/skills](https://github.com/the-aurora-lab/skills): Test Readers (blind reader personas for your draft) and Citable Python Packages from Research Code
- **Paid skills and bundles:** [Agensi](https://www.agensi.io/creators/aurora-lab), or as direct zip downloads on [Gumroad](https://theauroralab.gumroad.com)
- **Updates:** [@theauroralab on X](https://x.com/theauroralab)
- **Contact:** auroralab.skills@gmail.com
